# 离线呼吸分析与多算法对比模块 (Breath Extraction Module)

本模块用于对已采集的压力矩阵序列进行深度离线分析。它集成了多种信号处理与时空模态分解算法，旨在从复杂的压力背景中精准提取人体微弱的呼吸特征。

---

## 核心功能

1. **空间与通道预处理**
   - **空间平滑**：引入 **2D 高斯滤波 ($\sigma=0.8$)** 与中值滤波级联，有效抹平传感器像素点跳变，稳定臀部受力 ROI 的中心定位。
   - **小波自适应降噪**：时域采用小波变换 (db4) 自适应软阈值降噪 ($\alpha=1.2$)，在滤除高频抖动和基线漂移的同时，完整保留呼吸波峰波谷特征。
   - **频带锁定**：使用 3 阶 Butterworth 带通滤波器 ($0.1 - 0.5\text{ Hz}$) 锁定生理呼吸频段。

2. **多 ROI 空间协同分析与盲源分离**
   - **MVMD (多变量变分模态分解) [NEW]**：时空协同分析的集大成者。自动提取 4 个核心受力象限的局部均值 1D 序列（组成 $4 \times T$ 通道矩阵），在 ADMM 变分框架下联合分解，并利用 **FastICA (独立成分分析)** 融合呼吸源。呼吸估算最稳定 (标准差仅 2.51)，有效抑制局部体动，且无信号脱落。
   - **Multi-ROI ICA [NEW]**：轻量化空间协同方案。直接提取 4 象限 ROI 通道，通过 FastICA 时空盲源分离和相位对齐融合，单窗处理仅耗时 **32.2 ms**，能有效消除共模运动噪声，是最具工程实时落地价值的方案。
   - **SMVMD (稀疏多变量变分模态分解)**：将活跃格点通道过滤的方差门限提升至 `12.0`，过滤掉无用低方差噪点通道，滑窗时间大幅压缩至 **148 ms**。注意：在压力变化极温和的静止期可能引发 12% 的信号脱落。

3. **传统单通道提取算法**
   - **VMD / VMD_FPR**：变分模态分解。VMD_FPR 引入 MAPE 自动寻优残差拐点以自适应确定模态数 $K$，能有效拟合动态呼吸，但计算较慢 (单窗 1.0s)。
   - **EMD**：经验模态分解。采用“全员入选+生理频段能量排序”重构，分解速度快 (14 ms)，但模态混叠率高 (44.0%)。
   - **AFD**：自适应傅里叶分解。通过在呼吸频段内检索正交基函数投影，信噪比极佳 (30.40 dB)，模态混叠率仅 14.0%，但对突变噪声较敏感。

4. **BPM (每分钟呼吸数) 测算算法加固**
   - **常规波峰法 (Peak)**：将固定的幅度差门限修改为**基于信号标准差自适应设定的 Prominence 门限 ($std \times 0.5$)**，以克服运动伪影极大值的干扰。
   - **特征点法 (FPR)**：在 VMD-FPR 提取中加入**物理最小寻峰间距限制 (1.5s)**，防止高频杂散毛刺导致呼吸次数被多次计数，BPM 估计全面收敛至生理合理范围。

## 文件说明

- **`data_loader.py`**：负责解析带时间戳的座垫原始 TXT 压力数据文件并还原为时空矩阵。
- **`preprocess.py`**：单帧空间滤波（高斯+中值）、整段数据清洗（剔除传感器坏帧）的预处理核心。
- **`main_UI.py`**：PyQt5 GUI 主界面控制塔，负责参数配置、滑窗控制、实时可视化及多算法一键解算。
- **`analyze_test.py`**：滑窗测试脚本，用于批量评估所有算法在全段滑动窗口下的耗时和估计稳定性。
- **`algorithms/`**：
  - `base.py`：包含小波去噪、带通滤波、BPM 估计（Peak、FPR）、自适应多 ROI 提取与 FastICA/PCA 融合等基础工具。
  - `emd_extract.py`：EMD 呼吸提取接口。
  - `vmd_extract.py` / `vmd_MAPE.py`：VMD / VMD_FPR 呼吸提取接口。
  - `afd_extract.py`：AFD 呼吸提取接口。
  - `smvmd_extract.py`：向量化稀疏 SMVMD 提取接口。
  - `mvmd_extract.py`：多变量 MVMD 提取与通道 FastICA 融合核心算法。
  - `multi_roi_ica_extract.py`：多象限直接 FastICA 提取与融合核心算法。
