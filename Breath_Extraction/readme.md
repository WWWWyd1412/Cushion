# 离线呼吸分析与多算法对比模块

本模块用于对已采集的压力矩阵序列进行深度离线分析。它集成了多种信号处理与模态分解算法，旨在从复杂的压力背景中精准提取人体呼吸特征。

## 核心功能

- **数据解析**：支持解析带时间戳的原始 TXT 数据，并自动还原为 32×32 的时空矩阵序列。
- **多维去噪**：
  - **空间域**：利用中值滤波和高斯模糊清洗单帧图像。
  - **时间域**：引入小波自适应去噪（Wavelet Denoising）算法，在保留呼吸峰值的同时抑制基线漂移和高频毛刺。
- **模态分解提取**：
  - **VMD**：变分模态分解，通过设定带宽限制提取最纯净的呼吸分量。  
  - **EMD**：经验模态分解，通过本征模态函数 (IMF) 提取非线性波动。
  - **AFD**：简化版自适应傅里叶分解，在呼吸频段内执行频率基函数搜索。

## 文件说明

- **data_loader.py**：离线加载 `.txt` 数据文件并转换为 NumPy 格式。
- **preprocess.py**：该模块负责对原始数据进行“清洗”和“增强”，是后续算法准确提取特征的基础。
- **algorithms/**：该模块包含了多种时频分解算法（VMD，EMD，AFD），用于从复杂的身体压力背景中分离出微弱的呼吸分量。 
- **main_UI.py**：该模块充当离线处理的“控制塔”，负责流程管理和可视化。
