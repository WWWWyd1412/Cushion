# 实时监测与呼吸提取模块

本模块负责柔性压力坐垫数据的实时采集、空间预处理及呼吸节律的动态显示。通过高性能绘图组件，用户可以在采集数据的同时直观观测到呼吸起伏及实时计算的呼吸频率。 

## 核心功能

- **高性能采集**：基于 `QThread` 线程异步读取串口数据，支持 460800 等高波特率传输，确保数据不丢帧。
- **智能布局**：采用 `QSplitter` 分割器实现自由拉伸界面。左上为参数配置，左下为热力图，右侧为全屏波形图。
- **动态 ROI 提取**：每一帧实时计算大于阈值（默认 100）的受力点均值，有效排除边缘噪声和硬件坏点（第 16 行/列）的干扰。
- **实时平滑显示**：集成 Savitzky-Golay 滤波器实时平滑一维信号，并自动进行去趋势处理，使波形始终围绕 0 轴波动，便于观察微小节律。

## 文件说明

- **main_RealTime.py**：主程序，负责 UI 调度、串口通信及缓冲区管理。
- **algorithms**：包含实时寻峰算法（BPM 计算），具体信号处理算法（VMD，EMD，AFD）和信号平滑逻辑。
- **preprocess.py**：负责单帧矩阵的视觉增强（中值滤波、高斯平滑）。
- **data_loader**：负责数据存储
