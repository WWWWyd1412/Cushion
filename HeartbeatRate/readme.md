# 离线心跳节律提取与多算法对比模块 (HeartbeatRate)

本模块是一个独立子模块，旨在从柔性压力坐垫采集的压力矩阵序列中，提取由于心脏射血搏动引起的人体微弱重心和躯体机械微震信号——**球心动图（Ballistocardiogram, BCG）**，并自动计算心率。

由于心跳信号频率高、幅度极微弱，且深藏于大强度的呼吸信号和坐姿变动噪声中，本项目对信号预处理及各解调模态算法进行了针对性的重构与优化。

---

## 🎯 核心设计与调整

1. **时域联合带通滤波**
   * 心跳段的频率集中在 `0.8 Hz ~ 2.2 Hz` (对应 `48 ~ 132 BPM`)。
   * 本模块在 1D ROI 均值降维后，引入了三阶 Butter 带通滤波器 `(lowcut=0.8, highcut=2.2)`，彻底去除了 0.5 Hz 以下的呼吸大波和直流体重分量，让心搏微弱波动凸显。

2. **缓和小波自适应去噪**
   * 为了保留 BCG 心跳的 J 峰波形细节，去噪阈值因子 $\alpha$ 从呼吸提取中的 `1.2` 下调至 `0.3`。

3. **生理频段的模态重构**
   * 变分模态分解 (VMD) 阶数调整为 `K=6`。
   * 模态提取选择器仅允许重构频率在 `0.8 - 2.2 Hz` 内的模态分量，剔除带外杂波。
   * 寻峰算法 (`find_peaks`) 最小间距限制在 `fs * 0.4`（约合 4 帧），防止在单心动周期内把多余次峰错判为主峰。

## 📂 文件结构说明

* 📄 **`data_loader.py`**：负责解析时空压力矩阵数据（32x32 序列）。
* 📄 **`preprocess.py`**：剔除硬件异常大值，并进行空间域 3x3 中值滤波预处理。
* 📂 **`algorithms/`**：核心时频解调与分解算法包。
  * 📄 **`base.py`**：级联滤波链路、小波去噪、自适应 ROI 降维以及心率计算 (BPM/FPR)。
  * 📄 **`emd_extract.py`**：基于经验模态分解 (EMD) 的心脉提取。
  * 📄 **`vmd_extract.py`**：基于变分模态分解 (VMD) 的心脉提取。
  * 📄 **`acmd_extract.py`**：基于自适应线性调频模态分解 (ACMD) 的心脉提取。
* 📄 **`main_UI.py`**：心跳提取的交互式 GUI (PyQt5) 分析软件。

---

## 🚀 启动与使用指南

在命令行中切换到本目录下，直接运行主界面程序：

```bash
python main_UI.py
```

### 操作说明：
1. 点击 **"选择 TXT 文件"**，选择 `new_CUSHION/data/` 目录下的压力文本数据。
2. 点击 **"加载原始数据"** 绘制并查看压力变化总趋势。
3. 点击 **"执行预处理"** 对每帧矩阵去除噪点。
4. 下拉框选择想要对比的算法（如 EMD、VMD 或 ACMD），点击 **"提取心跳波形"**。
5. 系统将在右侧窗口生成两幅精美图表：
   * **时域图**：显示 J波心搏重构线，并以蓝色圆点高亮标记自动检测出的心跳主峰。
   * **频域图**：显示幅度谱线并自动标注位于生理心率带内的功率谱主峰位置及其所对应的心率 (BPM)。
