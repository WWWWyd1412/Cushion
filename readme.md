# 柔性压力阵列坐垫监测系统 (Project new_CUSHION)

本项目基于 32×32 柔性压力传感器阵列，开发了一套集实时数据采集、热力图可视化、呼吸节律提取及离线分析于一体的科研系统。

## 目录结构

- **Real_Time_Extraction/**: 实时监测与提取模块。包含高性能串口采集程序，支持实时波形平滑显示和区域压力分析。
- **Breath_Extraction/**: 离线呼吸分析模块。包含基于 VMD、EMD、AFD 等高级算法的呼吸波形提取逻辑。
- **data/**: 数据存储文件夹。默认存放系统采集并生成的 `.txt` 格式压力矩阵数据。
- **heat.py**: 基础版实时热力图采集程序。
- **extract.py**: 基础版呼吸特征提取脚本。
